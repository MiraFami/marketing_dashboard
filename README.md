# aramisauto Insight, dashboard interactif

Dashboard d'analyse client aramisauto, developpé avec Dash (Plotly).

## Prerequis

- Python 3.9+ installé sur la machine
- Connexion internet (chargement des polices)
- Les données doivent etre présentes dans `../01_data/`

## Lancement rapide

### Double-clic (le plus simple)



 Ouvrir un terminal et lancer `python3 start.py` 

Le script crée automatiquement un environnement virtuel, installe les dépendances et ouvre le navigateur.




## Pages du dashboard


Le dashboard contient 7 pages, une page:

1. Vue d'ensemble 
2. Hypothèses
3. Segmentation
4. Catalogue
5. Géographie
6. Benchmark
7. Recommendations
